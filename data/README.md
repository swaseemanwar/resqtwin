# Data

This directory documents project data and may contain small samples that are safe and legal to redistribute.

Every committed dataset must state:

- source and owner;
- licence or written redistribution permission;
- whether it is measured, authoritative, synthetic, or derived;
- collection or generation method;
- units, coordinate reference system, timestamps, and known limitations; and
- transformations needed to reproduce it.

Keep raw, processed, and generated working datasets in the ignored `data/raw/`, `data/processed/`, and `data/generated/` directories. Never commit personal, sensitive, or operational field data without an explicit data-management decision.
