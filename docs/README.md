# Documentation

Use this directory for shared, verified project knowledge.

Likely document types include:

- official requirements and organizer clarifications;
- decision records marked `PROPOSED`, `LOCKED`, or `SUPERSEDED`;
- research notes with sources and access dates;
- architecture and interface documents after scope lock; and
- verification evidence and demonstration instructions.

Do not copy local assistant memory into tracked documentation. Convert useful conclusions into concise, team-reviewed records with clear provenance.
