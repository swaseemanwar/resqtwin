# Hardware

This directory is reserved for hardware implementation material once the inventory and interfaces are locked.

Appropriate future content includes:

- firmware source;
- board and sensor interface definitions;
- wiring and power notes;
- calibration procedures;
- safety limits and fail-safe behavior; and
- hardware-in-the-loop test instructions.

Do not commit credentials, vendor-generated build trees, or an assumed hardware architecture before compatibility is verified.
